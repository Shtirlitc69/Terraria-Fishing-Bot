# Terraria Fishing Bot

Помощник для рыбалки в Terraria **1.4.5.6** на Windows. Читает процесс `Terraria.exe` и кликает ЛКМ в сохранённую точку заброса, когда на крючке предмет из списка. **Игру не патчит.**

Нужна обычная **32-битная Steam**-сборка. Не добавляйте `-autoarch` (запустится 64-битная Terraria; бот к ней не подключится).

## Предупреждение

Мультиплеер может нарушать ToS. Надёжнее одиночка / офлайн.

Если старая версия этого проекта патчила `Terraria.exe`, восстановите оригинал через Steam **Проверить целостность файлов**. Этот бот игру не патчит и не восстанавливает.

## Стек

| Слой | Зачем |
|------|--------|
| Python 3.11 | Среда выполнения |
| customtkinter + pywin32 | Окно, вкладки, язык, клики мыши через `SendInput` |
| pymem + `ReadProcessMemory` / `WriteProcessMemory` | Подключение к `Terraria.exe`, скан JIT, чтение и запись полей |
| PyInstaller | Сборка onedir: `release\Fishing bot.exe` + `_internal\` |

## Кто за что отвечает

| Путь | Роль |
|------|------|
| [`src/Fishing bot.py`](src/Fishing%20bot.py) | GUI: Старт / Стоп / Точка заброса, список улова, статистика, настройки |
| [`src/memory_bot.py`](src/memory_bot.py) | Скан JIT `FishingCheck`, чтение `rolledItemDrop`, точка прицела, клик (подсечка / заброс) |
| [`src/data/catches.json`](src/data/catches.json) | ID и имена предметов Terraria |
| [`src/locale/`](src/locale/) | Строки интерфейса (en / ru) |
| `preferences.json` | Рядом с exe: список улова, язык, тема, сохранённая точка заброса |
| `statistics.json` | Рядом с exe: счётчики улова |

Цепочка:

```
Старт → подключение к Terraria.exe
  → скан JIT FishingCheck → Projectile._context.FishingAttempt.rolledItemDrop
  → один заброс игроком → позиция курсора сохраняется (клиентские координаты)
  → улов из списка → короткий клик ЛКМ в эту точку (подсечка, затем заброс)
Лог + statistics.json
```

## Как пользоваться

1. Запустите **32-битную** Terraria, зайдите в мир, возьмите удочку.
2. Дважды кликните [`release/Fishing bot.exe`](release/Fishing%20bot.exe). Папка `_internal` должна лежать рядом с exe.
3. Вкладка **Улов**. Галочки, пресеты (Рыба / Квест / Ящики) или **Выбрать все**. Для старта список не должен быть пустым.
4. Нажмите **Старт**. Дождитесь в логе, что хук найден.
5. Наведите курсор на воду в Terraria и **забросьте один раз**. Бот запомнит точку. Кнопка **Точка заброса** сбрасывает её, чтобы задать заново.
6. Держите игру на переднем плане. Курсор будет уезжать в сохранённую точку на каждой подсечке и забросе. Terraria и бот должны быть с **одним уровнем прав** (оба обычные или оба «от администратора»). Иначе Windows может резать `SendInput`, а чтение памяти продолжит работать.
7. **Стоп** снимает хук.

Язык, тема и авто-зелье / клавиша Quick Buff — вкладка **Настройки**. Смена темы применяется после перезапуска.

### Известное ограничение

Подсечка повторяет клик, пока не поднимется `itemAnimation` (первый клик часто не проходит). Заброс — **один** клик: заброс удочки не поднимает `itemAnimation`, а повтор снимает леску. Если в логе «подсечка не прошла» / фокус — проверьте точку заброса и что игра и бот запущены с одним уровнем прав.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Результат: `release\Fishing bot.exe`. Сначала закройте бота, иначе `_internal` может быть занят.

### Из исходников (без exe)

```powershell
pip install -r requirements.txt
python "src/Fishing bot.py"
```

`Fishing bot.bat` — запасной вариант: запускает `release\Fishing bot.exe`, если он есть, иначе `pythonw`.
